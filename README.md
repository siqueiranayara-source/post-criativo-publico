# 📝 Post Criativo Railam

Um projeto de estrutura criativa para posts com HTML e CSS, apresentando um design moderno e responsivo.

## 🎨 Características

- ✨ Design moderno com gradientes
- 📱 Totalmente responsivo
- 🎯 Componentes interativos
- 💫 Efeitos hover suaves
- 🎭 Interface intuitiva

## 📂 Estrutura do Projeto

```
post-criativo/
├── index.html      # Estrutura HTML do post
└── README.md       # Documentação
```

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/siqueiranayara-source/post-criativo-publico.git
```

2. Abra o arquivo `index.html` em seu navegador

3. Personalize o conteúdo conforme necessário

## 🎯 Componentes

- **Post Image**: Área de destaque com badge
- **Post Content**: Título, tags e metadados
- **Post Actions**: Botões de interação e compartilhamento
- **Post Footer**: Resumo e link para ler mais

## 🛠️ Personalização

Você pode facilmente personalizar:

- Cores: Modifique as cores do gradiente
- Conteúdo: Atualize o texto em `index.html`
- Fontes: Altere a fonte-family
- Dimensões: Ajuste os tamanhos conforme necessário

## 💡 Dicas

- Use cores contrastantes para melhor legibilidade
- Mantenha o design responsivo para mobile
- Teste em diferentes navegadores
