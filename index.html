📚 Comandos Git Essenciais

git init
Inicializa um novo repositório Git no diretório
git add .
Adiciona todos os arquivos alterados ao staging
git commit -m "mensagem"
Faz um commit com uma mensagem descritiva
git remote add origin https://github.com/usuario/repo.git
Conecta o repositório local ao repositório remoto
git push -u origin main
Envia os commits para o repositório remoto
git pull origin main
Atualiza o repositório local com as mudanças remotas
git branch -a
Lista todas as branches locais e remotas
git checkout -b nova-branch
Cria e muda para uma nova branch
git status
Mostra o status atual do repositório
git log --oneline
Exibe o histórico de commits de forma resumida
